# Выполненные изменения

## 1.0.1 — 24.09.2026

База: репозиторий команды `zxaty/KMG-Digital-Hackathon-otcysquad`, коммит `68c1dce` (indexer, analyzer, run_analysis, tech_spec_findings, 78 тестов).

### Добавлено
- `agent/main.py` — точка входа для CI: коды завершения 0/1/2, внутренний дедлайн 25 мин с частичным отчётом, журнал шага с числом нарушений и перечнем требований, аннотации `::error::/::warning::/::notice::`, запись в `GITHUB_STEP_SUMMARY` и `GITHUB_OUTPUT`; параметр `--commit` для каталогов вне git.
- `agent/rules.py` — детерминированные правила ИБ-01…ИБ-08 (18 находок на тестовом проекте, 0 на эталонной фикстуре) и 13 проверок несоответствий технической спецификации (раздел, не блокирующий пайплайн).
- `agent/llm_client.py` — клиент OpenAI-совместимого API на стандартной библиотеке: DeepSeek, Qwen, OpenAI, свой шлюз; повторы при 429/5xx, откат JSON-режима, учёт токенов, ошибка «модель недоступна» → код 2.
- `agent/report.py` — отчёт JSON + Markdown по ТЗ 4.6: сводка (коммит, время, длительность, результат, статус всех 8 требований), нарушения с фрагментом кода, обоснованием, критичностью, рекомендацией и основанием (пункты ТЗ/ТС), отдельный раздел несоответствий ТС, ограничения, ресурсы; удаление секретов.
- `agent/requirements_ru.py` — тексты требований по ТЗ, идентификаторы «ИБ-0N» в отчёте.
- `agent/prompts/system.md`, `agent/skills/IB-01…IB-08.md` — системная подсказка и навыки проверки по каждому требованию (п. 1.1 состава материалов).
- `.github/workflows/ib-security-check.yml` — шаг проверки ИБ до развёртывания, артефакт при любом исходе, проверка внешнего репозитория через `workflow_dispatch`; `.github/workflows/agent-selftest.yml` — тесты агента.
- Тесты: правила, клиент модели (локальный фейковый сервер), сквозные прогоны CLI (коды 0/1/2, дедлайн, мусорный ответ модели, оспаривание находки, дозапрос файлов), эталонная фикстура `tests/fixtures/clean_project`.
- Документация: `agent/README.md`, `agent/docs/Подход.md`, `agent/docs/Ресурсы.md`, образец отчёта и журнала шага `agent/reports/sample-rules-only/`.

### Изменено
- `indexer.py`: разбор `.docx` (абзацы и гиперссылки) для ИБ-06; инвентарь всех файлов проекта; путь к settings/urls в `meta`; поиск модулей аудита и прав доступа по содержимому, а не по жёсткому пути `portal/…`; исключение служебных каталогов по относительному пути.
- `analyzer.py`: в запрос к модели добавлены реальные исходники релевантных файлов с номерами строк, карта проекта, навык проверки и находки правил; дозапрос файлов моделью (`need_files`, второй раунд); слияние находок правил и модели, оспаривание только «вероятных» находок с контрдоказательством; фрагмент-доказательство — функция целиком с декораторами; устойчивый разбор JSON из ответа; промпт и формулировки на русском.
- `run_analysis.py`: интеграция правил, режим «только правила», дедлайн, параллельные запросы к модели (по умолчанию 3), объединение замечаний ТС без дублей.
- `tech_spec_findings.py`: формулировки на русском, указана критичность.
- Тесты команды адаптированы к русским формулировкам и новому ключу `inventory` индекса.
- `.gitignore`: `__pycache__`, `runtime/`, выходные отчёты.
